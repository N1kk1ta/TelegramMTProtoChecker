# Telegram Proxy Checker v5.17

## О программе

Telegram Proxy Checker — программа для проверки доступности Telegram MTProto-прокси, определения задержки (Ping), DC и результата MTProto handshake/ping. Программа позволяет загружать списки прокси, проверять их и быстро открывать или копировать готовые TG-ссылки.

## Что исправлено в v5.17

- Полностью переработана нормализация `secret` перед передачей в `mtp_ping`.
- Исправлена обработка Base64/Base64URL-секретов, в том числе 22, 23 и 24-символьных вариантов.
- Учтено правило `mtp_ping`: Base64-секреты с префиксом `7` обрабатываются как Base64 до проверки на hex.
- Валидный 16-байтный Base64-secret автоматически преобразуется в 32-символьный hex.
- Валидные `DD` и `EE` secrets после Base64-декодирования преобразуются в корректный формат для `mtp_ping`.
- Некорректные Base64 secrets с неизвестным префиксом, например `EF`, больше не передаются в `mtp_ping` и не вызывают ошибку `unexpected base64 secret value`.
- Для некорректного `secret` теперь показывается понятная ошибка непосредственно в результате проверки.
- Сохранены все функции предыдущих версий, включая timeout 150 мс, сортировку по Ping, прокрутку таблицы, копирование результатов MTProto и работу с TG-ссылками.
