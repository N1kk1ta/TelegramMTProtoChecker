# Telegram Proxy Checker v5.18

## О программе

Telegram Proxy Checker — Windows-программа для проверки доступности и скорости MTProto-прокси Telegram. Она принимает списки `tg://proxy` ссылок, проверяет подключение через `mtp_ping`, показывает Ping и результаты MTProto-проверки, а также позволяет открыть или скопировать готовую TG-ссылку.

## Что исправлено в v5.18

- Исправлена обработка Base64/Base64URL secret.
- Добавлена совместимость с публичными списками, в которых к обычному 16-байтному secret добавлены лишние байты в конце Base64-ссылки.
- Если после декодирования secret начинается не с `EE` или `DD`, первые 16 байт используются как обычный MTProto secret, а хвост рассматривается как лишние данные.
- Корректные `EE` Fake-TLS secrets сохраняются полностью вместе с SNI.
- Корректные `DD` secrets обрабатываются как Secure.
- Устранена ошибка `unexpected base64 secret value` для подобных ссылок.
- Сохранены timeout по умолчанию 150 мс, сортировка по Ping, прокрутка таблицы, копирование результатов и работа с TG-ссылками.
