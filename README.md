# Telegram Proxy Checker v5.19

## О программе

Telegram Proxy Checker — Windows-программа для проверки доступности и скорости MTProto-прокси Telegram. Она принимает списки `tg://proxy` ссылок, проверяет подключение через `mtp_ping`, показывает Ping и результаты MTProto-проверки, а также позволяет открыть или скопировать готовую TG-ссылку.

## Что исправлено в v5.19

- Исправлен разбор секретов в `mtp_ping`: 32-символьный hex-secret теперь распознаётся как обычный MTProto secret даже если начинается с цифры `7`.
- Устранена причина ошибки `Invalid URL: unexpected base64 secret value` для нормальных hex-secret, которые ошибочно принимались за Base64.
- Сохранена нормализация Base64/Base64URL-секретов перед проверкой.
- Сохранены поддержка Normal, Secure (`dd`) и Fake-TLS (`ee`/Base64).
- Timeout по умолчанию — **150 мс**.
- Сохранены вертикальная и горизонтальная прокрутка таблицы.
- ЛКМ по «Результаты MTProto» копирует содержимое ячейки.
- ЛКМ по TG-ссылке открывает её в Telegram, ПКМ копирует ссылку.
- После проверки прокси автоматически сортируются по Ping.
