# Telegram Proxy Checker v5.16

## О программе

**Telegram Proxy Checker** — Windows-программа для проверки доступности и скорости Telegram MTProto-прокси.

Программа позволяет загружать списки прокси, проверять их доступность, определять результат MTProto-проверки и задержку (Ping), а также получать готовые `tg://proxy` ссылки для открытия прокси в Telegram.

Программа предназначена для быстрого массового тестирования большого количества MTProto-прокси и удобного отбора рабочих серверов.

## Что исправлено в v5.16

- Исправлена нормализация MTProto `secret`: теперь программа не пытается преобразовывать произвольные Base64-значения в hex.
- Добавлена корректная обработка обычного 16-байтного secret в Base64/Base64URL.
- Добавлена корректная обработка Secure secret с префиксом `DD`.
- Добавлена корректная обработка Fake-TLS secret с префиксом `EE`.
- Некорректные или неподдерживаемые secret больше не передаются в `mtp_ping` как валидные.
- Устранена ошибка `unexpected base64 secret value` для корректных форматов secret.
- Сохранена оригинальная TG-ссылка — нормализация secret используется только для внутренней проверки.
- Сохранён timeout по умолчанию **150 мс**.
- Сохранена автоматическая сортировка результатов по Ping.
- Сохранено копирование результата MTProto по левому клику.
- Сохранены вертикальная и горизонтальная полосы прокрутки таблицы.
- Сохранено открытие TG-ссылки по левому клику и копирование по правому клику.
