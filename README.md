# Telegram Proxy Checker

**Telegram Proxy Checker** — Windows-приложение для поиска, проверки и анализа прокси-серверов, используемых для работы с Telegram.

Программа позволяет быстро загрузить список прокси, автоматически проверить их работоспособность и получить наглядный результат в единой таблице.

### Возможности

* 🔎 **Автоматическая проверка прокси** — массовое тестирование большого количества серверов.
* 📥 **Загрузка свежих списков** — быстрое получение и добавление актуальных прокси.
* 🌐 **MTProto и SOCKS5** — поддержка основных типов Telegram-прокси.
* ⚡ **Проверка скорости** — определение времени отклика сервера.
* 📊 **Наглядная таблица результатов** — статус, адрес, порт, тип и результаты проверки.
* 🟢 **Поиск рабочих прокси** — быстрое определение доступных серверов.
* 🔄 **Повторное тестирование** — возможность актуализировать результаты проверки.

### Как это работает

**Загрузить список → Проверить прокси → Получить результаты → Выбрать лучшие серверы**

Программа автоматизирует рутинную проверку прокси и позволяет за короткое время обработать большое количество серверов.

---

### 🎯 Для чего предназначена

Telegram Proxy Checker создан для пользователей, которым необходимо быстро находить **рабочие, доступные и быстрые прокси для Telegram** без ручной проверки каждого сервера.

**Просто загрузите список — программа сделает остальное.**
